# Build Spec — DuneSight (stub)

Not written yet. Produced in Phase 6, once the data is real, following handoff.md §8:

1. Stack: Vite + vanilla JS + CesiumJS, module layout (`src/main.js`, `src/layers/*.js`, `src/timeline.js`, `src/hud/`), token from `import.meta.env.VITE_CESIUM_TOKEN`, Leaflet 2D fallback.
2. Screens and interactions: fly-in, dune polygons by class, info card, modes, observed/projected timeline, HUD, "How we know" dossier, credits footer, then-vs-now toggle.
3. Style: dark "satellite intelligence" HUD.
4. Data contract: §4 verbatim plus the real values.
5. Offline capability.
6. Acceptance tests.
7. Explain-it notes per module.

Until then, build against the files in `public/data/`. Layout (three-site scope, see `docs/PLAN.md`): `public/data/sites.json` lists the sites (id, name, bbox, status, and a per-file `files` map saying which files are `real` and which are `placeholder`); each site with data has the full §4 file set, formats unchanged, under `public/data/<site_id>/` (e.g. `data/seih_al_hama/summary.json`). The app should add a site switcher and fly to the chosen site. Placeholder files are generated by `pipeline/make_placeholders.py` and carry `"placeholder": true`; currently only `seih_al_hama/wind_summary.json` is real.
